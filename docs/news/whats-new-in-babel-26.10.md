# What's new in babel 26.10

(dev)

After a hiatus of a couple of months, work on `babel` is resumed. 

## `tabular`

<span style="color:red;">⚠</span> **Potentially breaking change.**

For the reasons explained here, `tabular` was problematic with
right-to-left writing (RTL) and required some patching not always
leading to satisfatory results. Therefore and based on the principle of
minimal intervention, full RTL `tabular` stuff, with columns ordered
from right to left was made optional with `layout=tabular`.

With a recent change in the LaTeX kernel, one of whose purposes was to
improve the handling of bidi text, `tabular` now  behaves as
expected out of the box, and therefore what was (more or less) achieved
with `layout=tabular` becomes the default behaviour. Maybe some
fine-tuning is still necessary.

If for some reason you still need LTR columns with RTL text a new
option is provided: `layout=lrtabular`.

## Other changes

* New locale `farsi-latin` (thanks to
  [@RamtinMoslemi](https://github.com/RamtinMoslemi)).
* Removed the patch for `\textsuperscript` with `layout=counters`, too, no longer necessary
  (it was no-op, anyway).
* Fix: Variant was ignored with BCP 47 tags.

## Appendix

Since 2020 `babel` has provided a way to format dates based on the data
generated by external tools (see [What’s new in babel
3.45](https://latex3.github.io/babel/news/whats-new-in-babel-3.45.html)).
Sadly, they were system dependend, so it was useful only to some
extent. Now, a new package named `lua-calendrica`, by Udi Fogiel,
provides a system independent way to get the data for many calendars.
Here is an example with `lualatex`, which prints ‘11 Dey 1402’ [todo: a
better example]:
```tex
\documentclass{book}

\usepackage[farsi-latin]{babel}

\directlua{
local calendrica = require("calendrica")

local d = calendrica.new_date({year=2024, month=1, day=1}, calendrica.cal_gregorian)
local h = calendrica.as_date(d, calendrica.cal_persian)

token.set_macro("thesavedyear", h.year)
token.set_macro("thesavedmonth", h.month)
token.set_macro("thesavedday", h.day)

}

\begin{document}

% Persian calendar by default
\localedate\thesavedyear\thesavedmonth\thesavedday

\end{document}
```
A better interface will be provided in the near future.
