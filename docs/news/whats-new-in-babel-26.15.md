# What's new in babel 26.15

(dev)

For many years, most of the code was shared between \LaTeX{} and Plain,
but recent advances in \LaTeX{} have made joint maintenance
increasingly complex. Consequently, the code for Plain will be split
from main \babel{} for \LaTeX{} and essentially frozen. This does not
mean it is unmaintained, and the door remains open to future
improvements.
  
It needs to be cleaned up to remove unnecessary code in Plain. Note
also the engine specific files are still loaded.
